# Driver asset inventory

The original source ZIP was inventoried for QX, RT, and other driver script/module files. The inventory JSON records counts and sample paths.

The original executable `.sh` loaders and `.ko` modules are intentionally not copied into this app package because the source includes process-hiding-related drivers and unverified privileged operations. They are not run by the app. Use only modules you own or are authorized to test after independent compatibility and security review.
